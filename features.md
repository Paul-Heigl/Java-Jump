# Java Jump – Features

## Planned Features

### 1. Main Menu
- Start the game.
- Display instructions.
- Exit the application.

### 2. Level System
- Display levels using ASCII characters.
- Include platforms, gaps and obstacles.
- Mark the starting position and the goal.

### 3. Player Movement
- Move forward.
- Move backward.
- Jump.
- Combine jumping with horizontal movement.

### 4. Command Input
- Enter multiple movement commands.
- Store the commands in the entered order.
- Start the simulation after entering all commands.

### 5. Movement Simulation
- Execute the commands step by step.
- Update the player's position.
- Display the current level after each movement.

### 6. Collision Detection
- Detect collisions with platforms and obstacles.
- Detect when the player falls into a gap.
- Prevent movement through solid objects.

### 7. Win and Lose Conditions
- Complete a level by reaching the goal.
- Lose when falling into a gap or hitting a dangerous obstacle.
- Allow the player to retry a failed level.

### 8. Multiple Levels
- Include multiple levels.
- Increase difficulty with each level.
- Unlock new levels after completing previous ones.

## Optional Features

### 9. Command Limit
- Limit the number of commands available in certain levels.

### 10. Score System
- Award points for completing levels.
- Reward efficient solutions using fewer commands.

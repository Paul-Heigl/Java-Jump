# Java Jump – Agent Instructions

## Project Overview

Java Jump is a console-based Jump & Run puzzle game written in Java.

The player enters a sequence of movement commands to guide a character through a level.

## General Instructions

1. Use Java as the programming language.
2. Keep the application entirely console-based.
3. Do not use external game engines or graphical frameworks.
4. Write simple, readable and well-structured code.
5. Use meaningful variable and method names.
6. Avoid unnecessary complexity.

## Code Guidelines

1. Use classes and methods to organize the code.
2. Use two-dimensional arrays to represent levels.
3. Use Scanner to read user input.
4. Use loops and conditional statements for game logic.
5. Use a switch statement to process movement commands.
6. Keep movement logic, collision detection and level rendering separated where possible.

## Game Logic

1. Display the level before accepting commands.
2. Allow the player to enter a sequence of commands.
3. Execute the commands in the correct order.
4. Check for collisions and falling after each movement.
5. Stop the simulation when the player wins or loses.
6. Allow the player to restart a failed level.

## Development Instructions

1. Implement one feature at a time.
2. Test each feature before continuing.
3. Keep the code understandable for beginner Java developers.
4. Update features.md when adding or changing features.
5. Make sure the application runs without external dependencies.

## Project Goal

Develop a functional Java console game that demonstrates basic programming concepts such as arrays, loops, methods, conditional statements and user input.

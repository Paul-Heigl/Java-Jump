# Java Jump

**Author:** Paul Heigl

## Description

Java Jump is a console-based Jump & Run puzzle game developed in Java.

The player has to navigate a character through different levels by entering movement commands. Instead of controlling the character in real time, the player plans a sequence of movements before starting the simulation.

The goal is to reach the end of each level without falling into gaps or hitting obstacles.

## How to Play

1. Start the application.
2. Select a level.
3. Look at the level displayed in the console.
4. Enter movement commands such as `forward`, `backward`, `jump` or `jump+forward`.
5. Start the simulation.
6. Watch the character execute the commands.
7. Reach the goal to complete the level.

If the character falls into a gap or hits a dangerous obstacle, the level is failed and the player can try again.

## Technologies

- Java
- Java Console
- Scanner for user input
- Arrays for level representation
- Loops and conditional statements for game logic

## Project Goal

The goal of this project is to create a simple and entertaining console game while practicing fundamental Java programming concepts.
